# Refonte du site « Combattre pour le socialisme »

**Maquette en ligne :** https://jauj.github.io/test/

Travail de refonte de [combattrepourlesocialisme.com](https://combattrepourlesocialisme.com) : audit, propositions et maquette.

| Dossier / fichier | Contenu |
|---|---|
| [`maquette/`](maquette/) | Maquette HTML/CSS : Accueil, Publications (liste + recherche par thème), Textes, Qui sommes-nous, S'abonner, exemple d'article. Générée par `maquette/outils/gen_pages.py`. |
| [`AUDIT.md`](AUDIT.md) | Audit du site WordPress actuel (structure, contenus, design, technique). |
| [`PROPOSITIONS-DESIGN.md`](PROPOSITIONS-DESIGN.md) | Normes d'accessibilité (WCAG 2.2 / RGAA), palette et contrastes, modèle de données pour la recherche, modifications proposées. |
| [`audit-captures/`](audit-captures/) | Captures du site actuel (ordinateur et mobile). |
| [`site-wordpress/`](site-wordpress/) | Miroir HTML/CSS/images du site actuel (sans les PDF). |
| [`site-wordpress-api/`](site-wordpress-api/) | Inventaire complet exporté de l'API WordPress (articles, pages, catégories, étiquettes, médias). |
| [`ancien-site-free/`](ancien-site-free/) | Copie et audit de l'ancien site socialisme.free.fr. |

La branche `gh-pages` contient uniquement la maquette, publiée par GitHub Pages.
